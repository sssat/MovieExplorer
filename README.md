# MovieExplorer — 영화 탐색 프로그램

C#·WPF·MSSQL을 활용해 상영 중인 영화, 개봉 예정 영화, 과거 개봉 영화를 탐색하고 관심 영화를 저장하는 Windows 데스크톱 포트폴리오 프로젝트입니다.

## 목표 기능

| 화면 | 기능 | 상태 |
| --- | --- | --- |
| 영화 목록 | 다크 테마 카드, 검색, 장르 필터, 간단한 정보 보기 | 샘플 데이터로 구현 |
| 상영 중 | 한국 지역 기준 TMDB 상영작 목록 | 예정 |
| 개봉 예정 | 한국 지역 개봉 예정 영화와 개봉일 | 예정 |
| 지난 영화 | 과거 개봉 영화를 제목·연도·장르로 탐색 | 예정 |
| 영화 상세 | 실제 포스터, 줄거리, 개봉 정보, TMDB 평점·평가 수·사용자 리뷰 | 예정 |
| 관심 영화 | 관심 목록, 감상 여부, 메모를 MSSQL에 저장 | 예정 |

극장별 시간표, 좌석 선택, 예매 및 결제는 구현 범위에 포함하지 않습니다.

## 데이터와 표시 기준

- TMDB를 실제 영화 정보의 기본 출처로 사용합니다.
- 상영 중 목록은 TMDB의 한국 지역 개봉 정보를 기반으로 합니다. 특정 극장에서 오늘 실제로 상영하는지 또는 예매 가능한지를 보장하지 않습니다.
- 지역별 개봉일과 기본 개봉일을 구분하고, 한국 개봉일이 없는 경우 해당 사실을 표시합니다.
- 과거 개봉 영화는 개봉일 기준 분류입니다. 상영 종료를 의미하지 않습니다.
- KOBIS 박스오피스 순위·관객 수는 필요할 때 추가할 확장 기능입니다.
- MSSQL은 관심 영화, 감상 여부 및 개인 메모를 저장하는 데 사용합니다.
- API 인증 정보는 환경 변수 또는 Git에서 제외한 로컬 설정에 보관합니다.
- 실제 연동 시 TMDB의 출처·로고 표기 요구사항을 적용합니다.

현재 화면의 영화 6편과 포스터는 **가상의 시연 자료**입니다. 아직 API 호출, 실제 영화 조회, DB 저장은 구현하지 않았습니다.

## 개발 순서

1. TMDB 인증 설정과 영화 조회 서비스를 연결합니다.
2. 상영 중·개봉 예정·지난 영화 화면을 구성하고 검색 및 페이지 이동을 연결합니다.
3. 포스터·상세정보, 로딩·오류·빈 결과 처리를 구현합니다.
4. MSSQL에 관심 영화와 감상 기록을 저장합니다.

## 실행

- Visual Studio에서 `MovieExplorer.sln`을 열고 .NET 데스크톱 개발 환경 및 .NET 9 SDK를 준비합니다.
- F5를 눌러 현재 영화 목록 미리보기를 실행합니다.
- 솔루션·C# 프로젝트·네임스페이스·실행 파일 이름은 `MovieExplorer`입니다.
